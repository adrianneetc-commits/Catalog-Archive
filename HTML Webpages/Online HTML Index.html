Markdown Live Preview

Here is a responsive Markdown editor with a live preview. It uses a side-by-side layout (which stacks on mobile) and integrates the lightweight marked.js library via CDN to handle the Markdown-to-HTML conversion on the fly. I've also included buttons to copy your Markdown, copy the rendered HTML, or export the raw Markdown as a .md file.
