### Gemini

Here are the primary Notion API HTTP requests used to update **views**, **databases**, and **pages** in your workspace.

### Notion API Update Endpoints

Target ObjectHTTP MethodEndpoint URLRequired Payload ParametersKey Modifiable Fields**View**`PATCH``[https://api.notion.com/v1/views/](https://api.notion.com/v1/views/){view_id}``view_id` (Path)Name, `filter`, `sorts`, view configuration**Database**`PATCH``[https://api.notion.com/v1/databases/](https://api.notion.com/v1/databases/){database_id}``database_id` (Path)`title`, `description`, `properties` (schema/columns), `icon`, `cover`**Page**`PATCH``[https://api.notion.com/v1/pages/](https://api.notion.com/v1/pages/){page_id}``page_id` (Path)`properties` (column values/data), `icon`, `cover`, `archived` / `in_trash`

### Request Payload Examples

> All requests require the headers `Authorization: Bearer ` and `Notion-Version: 2026-03-11` (or your active version).
>
> Notion

#### 1. Update a View (`PATCH /v1/views/{view_id}`)

Notion API

Modifies a saved view’s layout configurations, filters, or sorts on a database.

JSON

PATCH /v1/views/a3f1b2c4-5678-4def-abcd-1234567890ab
Host: api.notion.com
Content-Type: application/json

{
  "name": "Active Tasks View",
  "filter": {
    "property": "Status",
    "status": {
      "equals": "In Progress"
    }
  },
  "sorts": [
    {
      "property": "Due Date",
      "direction": "ascending"
    }
  ]
}


#### 2. Update a Database Schema (`PATCH /v1/databases/{database_id}`)

Modifies the database metadata or column definitions (schema).

Notion

JSON

PATCH /v1/databases/d9824bdc-8445-4327-be8b-5b47500af6ce
Host: api.notion.com
Content-Type: application/json

{
  "title": [
    {
      "text": {
        "content": "Project Tracker 2026"
      }
    }
  ],
  "properties": {
    "Priority": {
      "select": {
        "options": [
          { "name": "High", "color": "red" },
          { "name": "Low", "color": "gray" }
        ]
      }
    }
  }
}


#### 3. Update a Page / Database Item (`PATCH /v1/pages/{page_id}`)

Modifies specific field values (row data) inside a page or database row.

JSON

PATCH /v1/pages/b55c9c91-384d-452b-81db-d1ef79372b75
Host: api.notion.com
Content-Type: application/json

{
  "properties": {
    "Name": {
      "title": [
        {
          "text": {
            "content": "Updated Task Title"
          }
        }
      ]
    },
    "Status": {
      "status": {
        "name": "Done"
      }
    }
  }
}
