# Contributing to Catalog-Archive

Thank you for your interest in contributing to this project!

## How to Contribute

1. **Create a Feature Branch**
   - Branch from `develop`: `git checkout -b feature/your-feature-name`

2. **Make Your Changes**
   - Ensure your changes are well-organized and documented

3. **Commit Your Work**
   - Use clear, descriptive commit messages

4. **Push and Create a Pull Request**
   - Push to your feature branch
   - Create a PR against the `develop` branch

## Guidelines

- Keep commits atomic and focused
- Document any new features or changes
- Update the README if adding new directories or functionality

## Questions?

Feel free to open an issue or discussion for any questions or suggestions.
